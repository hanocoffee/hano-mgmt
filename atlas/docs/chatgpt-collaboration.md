# ChatGPTとの協働ガイド

Atlasは「ChatGPTで壁打ち・戦略検討 → Claude Codeで実装・統合」という分担で開発します。
このドキュメントは、ChatGPTに相談するときにコピペで使える素材集です。

## 使い方

1. 下の「プロジェクトコンテキスト」をChatGPTの会話の最初に貼る
2. 相談テーマのプロンプトを選んで（または自分の質問を）続けて送る
3. ChatGPTの回答（仕様案・アイデア・優先順位）をそのままClaude Codeに渡す
   - 例: 「ChatGPTとこういう結論になった。この仕様で実装して →（回答を貼り付け）」

## プロジェクトコンテキスト（ChatGPTに最初に貼る）

```
あなたは事業開発とプロダクト戦略の壁打ち相手です。

【プロジェクト: Atlas】
- 目的: AIを使って利益を生み出す事業を作る
- 現状: MVPとして「Market Research Engine」を構築済み
  - 複数の情報源から市場データを収集し、AI分析（要約・センチメント・
    キーワード・機会スコア0-1）を生成してSQLiteに保存するCLIツール
  - TypeScript / Node.js / pnpm / Docker対応
  - データソースとAI分析はインターフェース化されており、実装を
    追加するだけで拡張できる（現在: モックソース + ChatGPT API分析）
- 運営者: コーヒーショップ(hano coffee)を運営する小規模事業者。
  開発はClaude Codeが担当するので、技術的な実装可能性よりも
  「何を作るべきか・どう収益化するか」の議論に集中してほしい

回答は日本語で、結論→理由の順で簡潔に。実装タスクに落とせる
具体度で提案してください。
```

## 相談テーマのプロンプト例

### 1. 収益化の方向性

```
このMarket Research Engineを収益に繋げる選択肢を、初期投資・運用コスト・
到達までの速さで比較して3案に絞ってください。前提: 個人〜小規模運営、
既存事業はコーヒーショップ。自分の事業の意思決定に使う「自家利用」も
選択肢に含めて評価してください。
```

### 2. 追加すべきデータソースの優先順位

```
次に実装するデータソースの優先順位を決めたい。候補: RSS/ニュースAPI、
Google Trends、Reddit/X等のSNS、ECサイトレビュー、業界統計。
「無料/低コストで取得できるか」「分析した時のインサイトの濃さ」の
2軸で評価し、最初の2つを決めてください。それぞれ、どんなクエリで
何を調べるべきかの具体例も付けてください。
```

### 3. 分析アウトプットの設計

```
現在の分析結果は summary / sentiment / keywords / opportunityScore(0-1) です。
「儲かる事業機会を見つける」目的に対してこのスキーマで十分か？
足すべきフィールド（例: ターゲット顧客、競合密度、参入障壁、
推定市場規模カテゴリ）があれば、優先度付きで提案してください。
```

### 4. 仕様レビュー依頼のテンプレート

```
以下はこれから実装する機能の仕様案です。ユーザー価値・スコープの
過不足・優先順位の観点でレビューしてください。技術的な実装方法の
指摘は不要です。

（ここに仕様を貼る）
```

## ChatGPTの結論をClaude Codeに渡すときのフォーマット

そのまま貼り付けでも動きますが、以下の形だと確実です:

```
【決定事項】(ChatGPTと相談した結論)
- 例: 次のデータソースはRSSとGoogle Trendsにする

【仕様・要件】
- （ChatGPTの回答から該当部分を貼り付け）

【保留・未決定】
- 例: 料金設定は後で決める
```

## 分担の目安

| 相談相手 | 得意なこと |
| --- | --- |
| ChatGPT | 事業アイデアの壁打ち、市場・収益化の議論、仕様の叩き台づくり、優先順位付け |
| Claude Code | 実装・テスト・リファクタリング、リポジトリ管理、仕様の技術的レビュー、CLI/Docker運用 |
| Atlas自身 | 収集した実データに基づく市場分析（ATLAS_ANALYZER=openai でChatGPTが分析エンジンとして動く） |
